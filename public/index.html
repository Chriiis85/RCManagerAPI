RCManager API / REST Endpoints

API Documentation

Bienvenido a la referencia oficial de la API de RCManager. Utiliza estos endpoints públicos para consultar datos en tiempo real sobre montañas rusas, parques temáticos, atracciones, espectáculos y restaurantes directamente desde nuestra base de datos PostgreSQL en Supabase.

Especificación de Respuesta

Todas las peticiones son de tipo GET, retornan datos en formato JSON (application/json) y tienen cabeceras CORS abiertas para integraciones web y móviles.

GET /api/coasters

Listar todas las Montañas Rusas

Devuelve la colección completa de montañas rusas almacenadas en la base de datos (29 registros reales), incluyendo fabricante, altura, velocidad, longitud, modelo y la información del parque temático anfitrión.

Atributos del Modelo

  • id integer

    Identificador único de la montaña rusa.

  • name string

    Nombre comercial de la atracción (ej: Shambhala, Dragon Khan).

  • manufacturer string

    Fabricante o empresa constructora (B&M, Intamin, Mack Rides).

  • speed float

    Velocidad máxima registrada en kilómetros por hora (km/h).

  • height float

    Altura máxima de caída en metros.

  • park object

    Relación anidada con el parque temático donde está instalada.

Request cURL
curl -X GET /api/coasters

GET /api/parks

Listar todos los Parques Temáticos

Recupera los 4 parques temáticos principales registrados en el sistema (PortAventura Park, Ferrari Land, Parque Warner Madrid y Parque de Atracciones de Madrid) junto con los datos de su operador gestor.

Atributos del Modelo

  • id integer

    ID del parque temático.

  • name string

    Nombre del parque.

  • country string

    País de localización del complejo.

  • city string

    Ciudad o municipio.

  • operator object

    Empresa operadora propietaria del recinto.

curl -X GET /api/parks

GET /api/attractions

Listar todas las Atracciones

Consulta el catálogo de 110 atracciones complementarias (dark rides, flat rides, torres de caída libre y atracciones acuáticas) asignadas a cada parque.

Atributos del Modelo

  • id integer

    ID único de la atracción.

  • name string

    Nombre de la atracción.

  • type string

    Tipo: FLAT_RIDE, WATER_RIDE, DARK_RIDE, SIMULATOR, etc.

  • status string

    Estado operativo (OPERATING, CLOSED).
